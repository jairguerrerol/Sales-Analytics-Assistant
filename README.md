# Sales Analytics Assistant
Sales Analytics Assistant is an interactive web application built with Python, Streamlit, Pandas, and Plotly.

Features:
CSV sales data uploads
Interactive dataset preview
Revenue and sales KPIs
Revenue visualization dashboard
Natural language business queries
Executive summary generation

Tech Stack:
Python
Streamlit
Pandas
Plotly

Sample Questions:
What is the best-selling product?
What is the total revenue?
Which category generated the most revenue?
Give me an executive summary.

Installation:
pip install -r requirements.txt
streamlit run app.py
